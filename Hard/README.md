|---------|-------------|

## Mindset for Hard Problems

```
Hard problems are not about whether you know the trick —
they are about whether you can think under pressure.

1. Do not panic if you have no idea immediately. That is normal.
2. Reduce the problem — can you solve a simpler version?
3. Draw examples — visual thinking breaks mental blocks.
4. Think about invariants — what must always be true?
5. If stuck after 30–45 min, study the approach, understand it deeply,
   and implement it from scratch without copying.
6. Come back to the problem later and solve it independently.
```
