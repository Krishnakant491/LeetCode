## About This Folder

This folder contains solutions to **Easy** difficulty problems from LeetCode, automatically synced via **LeetSync** whenever a solution is accepted.

Easy problems are essential for:

- Cementing understanding of core data structures (arrays, strings, hash maps)
- Building pattern recognition from the ground up
- Developing clean, efficient code habits
- Warming up before tackling Medium/Hard problems

## Common Patterns in Easy Problems

| Pattern | Description |
|---------|-------------|
| **Two Pointers** | Traverse from both ends toward the middle |
| **Hash Map / Set** | O(1) lookup to avoid nested loops |
| **Sliding Window** | Fixed-size window over linear data |
| **Binary Search** | Divide search space on sorted arrays |
| **Stack** | Matching pairs, balanced brackets |
| **Prefix Sum** | Precompute cumulative values |
| **Sorting** | Simplify problems by ordering data first |

---

## Tips for Easy Problems

- Always check for edge cases: empty input, single element, duplicates
- Aim for the optimal solution, not just a working one
- Practice writing clean code — interviews judge readability too
- If a brute force is O(n²), think if a hash map can bring it to O(n)
